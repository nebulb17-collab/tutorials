## On-screen steps

1. Écrivez votre menu : nom, description et prix de chaque produit.
2. Créez le lien WhatsApp : wa.me/ + votre numéro sans le « + ».
3. Ajoutez ?text= avec le message de commande déjà écrit.
4. Mettez ce lien sur un bouton « Commander » à côté de chaque produit.

## Proof shot to record

Tap « Commander » next to the Latte miel & cannelle, and film WhatsApp opening with the order already written.

## Make it real

Nothing to install. Change `WHATSAPP` (number without `+`) and the `MENU` object at the bottom of `index.html`.
